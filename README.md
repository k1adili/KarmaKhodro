# کارما خودرو (Karma Khodro)

اپلیکیشن اندروید ثبت سرویس و تعمیرات خودرو — امکان ثبت چند خودرو و رویدادهای
سرویس/تعمیر برای هرکدام، به همراه پشتیبان‌گیری و بازیابی اطلاعات.

**طراح و برنامه‌نویس:** کیوان عدیلی

---

## ۱) قبل از هر چیز: اضافه کردن فونت Vazirmatn (ضروری)

پروژه به‌طور کامل با فونت **Vazirmatn** پیکربندی شده، اما به دلیل مجوز و حجم فایل،
خود فایل‌های فونت داخل ریپازیتوری قرار داده نشده‌اند.

قبل از اجرای بیلد (چه لوکال، چه از طریق GitHub Actions) باید:

1. به آدرس زیر بروید و آخرین نسخه را دانلود کنید:
   https://github.com/rastikerdar/vazirmatn/releases
2. از پوشه `fonts/ttf` سه فایل زیر را بردارید و **با همین نام دقیق** در مسیر
   `app/src/main/res/font/` قرار دهید:
   - `vazirmatn_regular.ttf`
   - `vazirmatn_medium.ttf`
   - `vazirmatn_bold.ttf`
3. تغییرات را کامیت و پوش کنید.

جزئیات بیشتر در فایل `app/src/main/res/font/README.md` موجود است.
اگر این فایل‌ها نباشند، هم بیلد لوکال و هم GitHub Action با پیغام خطای
مشخص متوقف می‌شوند (تا بدون فونت اشتباهی ساخته نشود).

## ۲) ساخت خودکار APK با GitHub Actions

یک workflow آماده در مسیر `.github/workflows/build-apk.yml` قرار دارد که:

- با هر `push` یا `pull request` به شاخه `main`/`master` اجرا می‌شود.
- همچنین می‌توانید آن را دستی از تب **Actions** ریپازیتوری با دکمه
  **Run workflow** اجرا کنید.
- ابتدا وجود فایل‌های فونت را چک می‌کند.
- سپس دو نسخه APK (Debug و Release بدون امضا) می‌سازد.
- در پایان، فایل‌های APK را به‌صورت **Artifact** به نام `KarmaKhodro-APK`
  ضمیمه‌ی اجرای workflow می‌کند؛ از تب Actions → روی اجرای موردنظر →
  پایین صفحه، بخش Artifacts قابل دانلود است.

### نکته درباره نصب مستقیم روی گوشی
- فایل **debug** با امضای پیش‌فرض دیباگ، مستقیماً روی گوشی قابل نصب است.
- فایل **release** بدون امضا (unsigned) است و برای انتشار واقعی باید یک
  keystore بسازید و signing config را در `app/build.gradle.kts` اضافه کنید.

## ۳) ساخت لوکال (اختیاری، در Android Studio)

1. پروژه را در Android Studio (Hedgehog یا جدیدتر) باز کنید.
2. صبر کنید Gradle Sync تمام شود.
3. از منوی Build → Build Bundle(s) / APK(s) → Build APK(s).

---

## ۴) امکانات پیاده‌سازی‌شده

- ثبت چند خودرو (نام، برند/مدل، پلاک، سال، رنگ، کیلومتر فعلی، یادداشت).
- برای هر خودرو، ثبت نامحدود رویداد سرویس/تعمیر (عنوان، تاریخ، کیلومتر،
  هزینه، نام تعمیرگاه، توضیحات، یادآوری کیلومتر سرویس بعدی).
- ویرایش و حذف خودرو و رویدادها.
- **پشتیبان‌گیری**: خروجی گرفتن از کل اطلاعات به یک فایل JSON با انتخاب محل
  ذخیره دلخواه (صفحه تنظیمات).
- **بازیابی**: وارد کردن مجدد اطلاعات از فایل پشتیبان (جایگزینی کامل داده‌ها).
- صفحه تنظیمات شامل نام طراح (کیوان عدیلی) و شماره نسخه برنامه.
- آیکون برنامه ترکیبی از خودرو و آچار سرویس (هم به‌صورت Adaptive Icon برای
  اندروید ۸ به بالا، هم فایل‌های راستری برای نسخه‌های قدیمی‌تر).
- ساختار داده‌ها با Room (SQLite) و رابط کاربری با Jetpack Compose.

## ۵) ساختار پروژه (خلاصه)

```
app/src/main/java/ir/keyvanadili/karmakhodro/
├── data/              # Entity ها، Dao ها، Database، Repository
├── backup/            # BackupManager (Export/Import JSON)
├── ui/
│   ├── theme/         # رنگ، تایپوگرافی (فونت Vazirmatn)، تم
│   ├── navigation/     # مسیر بین صفحات
│   ├── screens/        # صفحات: لیست خودرو، فرم خودرو، جزئیات، فرم سرویس، تنظیمات
│   └── viewmodel/      # MainViewModel
└── util/               # ابزار تاریخ
```

Application ID: `ir.keyvanadili.karmakhodro`
